# 漫游签（Wanderlit）

一个面向中国境内旅行的路线灵感与足迹记录网站。公开测试版支持：

- 在演示地图上点亮县级足迹，并保存在当前浏览器
- 按出发县区、预算、日期、人数、偏好和交通方式生成 K 条路线
- 查看每日行程、预算拆分和地图线路
- 通过路线助手提出修改，并确认后同步更新计划
- 导出完整路线长图或每日行程图

## 本地运行

```bash
npm install
npm run dev
```

打开终端显示的本地网址即可体验。生产构建：

```bash
npm run build
```

## 可选的大模型配置

复制 `.env.example` 为 `.env.local`，填写任意兼容 Chat Completions 的模型服务：

```env
LLM_API_KEY=
LLM_BASE_URL=
LLM_MODEL=
```

未配置时，路线助手自动使用内置演示规则，不影响页面测试。

## 数据与地图说明

当前仓库用于产品交互验证，地图为非测绘用途的坐标演示面板，路线和价格为测试数据。正式微信小程序版本需要接入腾讯位置服务或其他合规地图服务，并展示地图来源与审图信息；实时票价、天气和景区状态也应以授权接口及官方来源为准。

## 隐私

足迹和收藏默认只写入浏览器本地存储。服务密钥仅由服务端读取，禁止提交 `.env.local`。
